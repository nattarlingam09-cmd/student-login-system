Security & Session Architecture

Verified by Backend
HttpOnly Cookie Storage

Authentication token is invisible to JavaScript document.cookie, preventing XSS-based session hijacking.

Cryptographic Password Hashing

Stored passwords use bcrypt with cost factor 12. Password hashes are excluded from all API responses.

JWT Signature Verification

Every protected request is cryptographically validated using HMAC SHA-256 against the server's secret key.

SameSite CSRF Defense

Cookie configured with SameSite lax/strict attributes to prevent Cross-Site Request Forgery vulnerabilities.

System Architecture — College Evaluation Overview

Viva Ready

This application implements a complete Full-Stack 3-Tier Architecture. Below is the technical breakdown ready to demonstrate during project reviews:

Presentation Layer
Frontend Client

Semantic HTML5, responsive CSS3 glassmorphism, Vanilla JS Fetch API with HttpOnly cookie credentials.

Application Layer
Express & Node.js

RESTful API endpoints, centralized error handling, cookie-parser, and CORS policy middleware.

Security Layer
Auth & Cryptography

bcrypt password salt rounds (12), JWT signing/verification, input sanitization, and timing attack mitigation.

Data Layer
MongoDB & Mongoose

Schema validation, lowercase email normalization, unique compound index, and persistent cloud storage.
